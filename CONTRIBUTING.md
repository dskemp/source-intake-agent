# Contributing

Thanks for taking a look. This is a small personal-tools project, so
contributions are welcome but lightly managed.

## Found a problem?

Open an issue: <https://github.com/dskemp/source-intake-agent/issues/new/choose>

Pick **"Report a problem"** and fill in what happened, what you expected, and
which macOS version you're on. Logs from
`/tmp/claude-source-intake.out.log` and
`/tmp/claude-source-intake.err.log` are usually the most helpful thing you
can attach.

## Want to ask a question?

Use the **"Ask a question"** template at the same link. There's no such thing
as a silly one — if the README didn't answer it, the README probably needs
work.

## Want to suggest a change or send a patch?

Small, focused pull requests are easiest to review:

1. Fork the repo and create a branch off `main`.
2. Make the change. If it touches the worker or the dashboard, run it locally
   on a throwaway library before opening the PR.
3. Open a PR and describe **what the change does** and **why** in plain
   language. Screenshots help for any dashboard change.

Large refactors or new features: please open an issue first to talk it through
before writing the code — saves time on both sides.

## A note on scope

This tool is opinionated and personal. Features that are useful to a wide
audience are great. Features that only help one specific workflow may be
better as a fork. If you're unsure, ask in an issue first.
